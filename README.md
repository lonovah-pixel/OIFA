# SITE-VEIL

SCP-RP режим для Garry's Mod, построенный на DarkRP: исследовательский комплекс с живой инфраструктурой, допусками, содержанием аномальных объектов, исследованиями с непредсказуемым результатом, следами инцидентов и «директором напряжения».

> **Статус: в разработке, не проверено в игре.** Серверная логика проверяется автоматическими тестами без игры (LuaJIT + имитация API GMod/DarkRP + SQLite), клиентский код — линтером и дымовым тестом с заглушками. Запуск на настоящем сервере Garry's Mod в среде разработки был невозможен (Steam CDN недоступен), поэтому поведение в игре **не подтверждено**. Подробности — [PROJECT_STATUS.md](PROJECT_STATUS.md) и [TESTING.md](TESTING.md).

## Что внутри

- **Производный gamemode** `gamemodes/siteveil` (`base "darkrp"`) поверх **неизменённого** DarkRP (`gamemodes/darkrp`, коммит в `tools/darkrp.lock`). Городские механики (деньги, принтеры, имущество, магазины, партии товаров, голод, хит-меню, полиция) отключены на уровне модулей, команд и серверных обработчиков — см. [DARKRP_CHANGES.md](DARKRP_CHANGES.md).
- **Персонажи и служба**: несколько персонажей на игрока, 9 подразделений, должности с званиями, допусками, квотами от онлайна и whitelist, повышения и переводы, смены.
- **Инфраструктура «Живой комплекс»**: сектора, питание и резервные генераторы, связь, вентиляция, наблюдение, системы безопасности; неисправности, ремонт, обход, ограниченный саботаж; режимы комплекса (штатный, локальная тревога, нарушение содержания, блокировка сектора, эвакуация, восстановление).
- **Доступ**: удостоверения и временные пропуска, отзыв, журналы, аварийное открытие, зависимость дверей от питания.
- **Связь**: локальная речь, шёпот/крик, /me /do, OOC, обращения к администрации, рации с каналами и искажениями, голос по расстоянию и по рации.
- **Инвентарь и снабжение**: серверный инвентарь с вместимостью, шкафы с квотами, бюджеты подразделений, заявки и поставки, защита от дублирования.
- **Медицина и охрана**: ранения, кровотечения, переломы, ограниченная по времени недееспособность, стабилизация и реанимация; наручники с предельным сроком, конвой, обыск, журнал изъятий, задержание с основанием и сроком.
- **«Знание имеет допуск»**: досье SCP, закрытые разделы не отправляются клиенту без проверки допуска; отчёты, рецензии, распечатки, учёт утечек.
- **Объекты SCP**: протоколы содержания со стадиями (признаки → ухудшение → опасность → побег), игровые SCP-173, SCP-106, SCP-049 (с временной ролью SCP-049-2), SCP-096 — всё решает сервер.
- **«Исследования с неизвестным результатом»**: 9 протоколов, согласование опасных экспериментов, шаги, аварийное прекращение, воспроизводимый бросок исхода, защита от фарма.
- **«След инцидента»**: ограниченные по числу и времени следы, полевой осмотр, экспертиза с ограниченной точностью, дела.
- **«Директор напряжения»**: 12 событий с условиями, предупреждениями, задачами, исходами, перезарядками и лимитом одновременности; никогда не запускает событие, которое некому решить.
- **«Двойные задачи»**: необязательные скрытые задания по согласию, без убийств и разрушений, со следами для противоположной стороны.
- **Подкрепление**: МОГ по вызову командования во время кризиса, Повстанцы Хаоса — самостоятельно.
- **Инструменты администрации**: режим дежурства, панель (игроки, допуски, обращения, журнал аудита), редактор карты, управление директором и скрытыми заданиями, диагностика.
- **Аддоны** (`addons/`, подключаются отдельно через публичный API режима): интерком, обеззараживание сектора, тесла-ворота, видеонаблюдение (с опасностью лица SCP-096 на мониторе), игровой SCP-999, табло «Табель». См. [ADDONS.md](ADDONS.md).

Интерфейс — на русском языке, идентификаторы в коде — на английском.

## Требования

- Garry's Mod Dedicated Server (SRCDS), ветка без изменений API (проверялось по исходникам DarkRP `5abcf7a`).
- Никакого дополнительного контента из Workshop не требуется: используются модели и звуки Half-Life 2, входящие в Garry's Mod.
- Карта: любая. Режим не зависит от конкретной карты — разметка задаётся редактором карты в игре (см. [ADMIN_GUIDE.md](ADMIN_GUIDE.md)). Без разметки работает запасная автоматическая раскладка по точкам появления карты.
- Административный мод с поддержкой CAMI (FAdmin входит в DarkRP; ULX/SAM тоже подходят).

## Установка

1. Скопируйте каталоги `gamemodes/darkrp` и `gamemodes/siteveil` в `garrysmod/gamemodes/` сервера. DarkRP менять не нужно; если у вас уже стоит DarkRP, используйте ревизию из `tools/darkrp.lock` (другие ревизии не проверялись).
2. Возьмите пример конфигурации `server/server.cfg.example` → `garrysmod/cfg/server.cfg` и отредактируйте имя сервера, пароль RCON и т.п.
3. Запустите сервер:
   ```
   srcds_run -game garrysmod +gamemode siteveil +map gm_construct +maxplayers 32
   ```
4. Выдайте себе права суперадминистратора через ваш админ-мод, зайдите на сервер, создайте персонажа, откройте F4 → «Администрирование» → «Заступить на дежурство» и разметьте карту редактором (раздел «Разметка карты» в [ADMIN_GUIDE.md](ADMIN_GUIDE.md)). Разметка сохраняется в `garrysmod/data/siteveil/maps/<карта>.json`.
5. База данных (SQLite `sv.db` GMod) создаётся и мигрирует автоматически при первом запуске.
6. Необязательно: скопируйте нужные аддоны из `addons/` в `garrysmod/addons/` ([ADDONS.md](ADDONS.md)).

## Проверка исходников

```
tools/install_glualint.sh   # один раз: скачивает glualint 1.30.0 в tools/bin
tools/check.sh              # линтер + автоматические тесты (нужны python3 и пакет lupa)
```
