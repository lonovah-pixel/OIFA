# PROJECT_STATUS — SITE-VEIL

Статус: **в разработке**, сборка не готова к запуску на живом сервере.

## Реализовано

### Этап 1 — основа (код написан, серверная логика проверена тестами без игры)
- DarkRP `5abcf7a` завендорен без изменений в `gamemodes/darkrp/` (`tools/darkrp.lock`).
- Производный gamemode `gamemodes/siteveil/` (`DeriveGamemode("darkrp")`), загрузчик по манифесту с проверкой зависимостей.
- Отключение городских модулей DarkRP через `DarkRPPreLoadModules`, генерация профессий DarkRP из реестра ролей, реализации заглушек отключённых модулей, шлюз команд и смены профессий.
- Ядро: SQLite с версионируемыми миграциями и транзакциями, журнал аудита, RPC с проверкой схем и лимитами, синхронизация состояния дельтами, таймерные действия, воспроизводимый ГСЧ, диагностика.
- Персонажи: создание/выбор/удаление, слоты, имена, служебные номера, whitelist, квоты от онлайна, звания и повышение, переводы между подразделениями, лобби до выбора персонажа.
- Карта: хранение настроек по карте, валидация, автоматический запасной макет по точкам появления карты.
- Смены, задачи (обход постов и задачи по событиям) с записью результата в БД.
- Клиент: тема, компоненты, уведомления, HUD, кадровый терминал, меню F4 (удостоверение, подразделение, задачи, справка).

## Проверено
- `tools/check.sh`: glualint 1.30.0 без замечаний; 22 серверных теста (LuaJIT + мок API GMod/DarkRP + SQLite) проходят.
- **В игре не проверено**: SRCDS/GMod недоступны в среде разработки (Steam CDN заблокирован прокси).

## Известные проблемы и ограничения
- Клиентский код проверен только статически (glualint).
- Реальное поведение DarkRP при наследовании gamemode проверяется только по исходникам.
